# 安装与使用（小白版）

> 本文件假设你不需要懂技术，照着做即可。每一步都写了"点哪里"。

## 一、这个插件能做什么

在 DeepSeek Harness 左侧边栏底部（齿轮图标上方）加一个 **「重启」** 按钮。

点它 → 弹窗确认 → 应用关闭并在几秒后**自动重新打开**。

装插件、启用/禁用插件、卸载插件之后，用它就不用再手动"退出 → 去开始菜单找图标 → 重新打开"。

---

## 二、安装（两种方式，选一种）

### 方式 A：让 AI 帮你装（最省事）

在 DSH 里新建一个会话，对它说：

> 帮我把 `G:\file\deepseek\20261019重启功能插件开发\packages\dsh-restart-plugin`
> 这个目录安装成插件，并确认装好了。

AI 会用插件管理器安装它，并告诉你结果。

### 方式 B：自己用界面装

1. 打开 DSH 桌面版
2. 左侧边栏点 **设置**（齿轮）
3. 找到 **插件** 页面
4. 选择"从本地目录安装"之类的入口（不同版本措辞可能不同）
5. 把下面这个目录粘贴进去：

```
G:\file\deepseek\20261019重启功能插件开发\packages\dsh-restart-plugin
```

6. 确认安装

> **补充说明（⚠️ 未验证）**：方式 B 的具体菜单措辞我无法在本机逐一核对，
> 因为我没有你的鼠标和眼睛。如果找不到对应入口，用方式 A 最稳。

## 三、怎么用

1. 看左侧边栏**最下方**、齿轮图标**上方**，会出现一个环形箭头图标 + 「重启」文字
   - 侧边栏收起时只显示图标，把鼠标移上去会显示提示文字
2. 点它
3. 弹窗会告诉你：
   - 应用会关闭并在几秒后自动重新打开
   - 如果当前有任务在跑，会额外警告"正在运行的任务会被中断"
4. 点「重启」
5. 应用关闭 → **几秒后自动重新打开**，窗口会自己弹到最前面

> 有任务在跑时，按钮文字会变成「仍然重启」，需要你再点一次才真的重启。
> 这是故意的：防止误操作打断你正在跑的东西。

---

## 四、卸载

1. 设置 → 插件 → 找到「重启（Restart）」
2. 点卸载
3. 按提示重启应用（这时还没有重启按钮可用的话，就手动关掉再开）

## 五、出问题了怎么办

### 情况 1：点了重启，应用关了但没自动打开

手动从开始菜单（或桌面图标）打开 DeepSeek Harness 即可。
然后看这个日志文件，里面记录了看门狗干了什么：

```
C:\Users\<你的用户名>\AppData\Local\Temp\dsh-restart-watchdog-*.log
```

（按修改时间排序，最新的那个就是本次的）

### 情况 2：侧边栏找不到「重启」按钮

- 确认插件在"设置 → 插件"里是**已启用**状态
- 完全退出应用再重新打开（不是关窗口，要真的退出）

### 情况 3：重启后出现两个托盘图标

这是 Windows 的"幽灵图标"，**不影响功能、不占资源**：
旧实例被关掉时系统没来得及清理托盘条目，鼠标移上去它就会消失。
详见 [实现原理与风险.md](实现原理与风险.md) 的说明。

### 情况 4：想确认当前跑的是哪一版插件

在浏览器或命令行打开：

```
http://127.0.0.1:<端口>/dsh-restart-plugin/api/status
```

（端口号看应用启动后地址栏；每次启动可能不同）
返回内容里的 `watchdogVersion` 就是当前加载的插件版本。

## 六、开发者：怎么重新验证

```bash

node --test packages/dsh-restart-plugin/tests/host.test.mjs packages/dsh-restart-plugin/tests/client.test.mjs
```
